# Valgt konsept

**A1 · Sidemeny**, valgt av Osman Khalid 2026-11-10 etter to runder (se `../konsepter/decisions.md`).

Dette er et *konsept* (wireframe i SVG), ikke et ferdig design. Farger, fonter og CSS-regler låses i neste steg (BMAD UX: `DESIGN.md` og `EXPERIENCE.md`).

- `dagsoversikt.svg`: forsiden (FR-26) på PC og mobil.

Kjennetegn som skal videreføres:
- Sidemeny på PC (I dag, Mat, Trening, Historikk og Profil) og faner nederst på mobil.
- Ukestripe der grønn magnet betyr mat logget og oransje betyr trening logget. Den viser også hvordan man bytter dato (FR-27).
- Gul lapp med ett tall, «kcal igjen», og en forklarende setning (FR-7).
- Mat og Trening som trykkbare kort med måltider og økta, og «sist gang» per øvelse (FR-24).
- To hovedhandlinger: Logg mat og Start økt.
