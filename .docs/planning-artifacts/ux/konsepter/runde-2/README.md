# UX-konsepter, runde 2

Laget 2026-11-10 av Osman Khalid med Claude Code. Bygger på konsept A (Kjøleskapstavla) fra runde 1, gjort mer app-aktig (se `../decisions.md`). Alle har ukestripa med magneter, den gule lappen med «kcal igjen», egne ikoner og faner nederst på mobil. Data er fiktive.

| Variant | Idé | Styrke | Risiko |
|---|---|---|---|
| **A1 · Sidemeny** | Fast meny til venstre på PC. Mat og Trening er kort side om side. | Kjent app-oppsett, og alt vises på én skjerm. | Mest innhold på forsiden, og står litt i spenning til «få knapper». |
| **A2 · Mobil først** | Samme smale app-kolonne overalt, med faner nederst og en rund +-knapp for rask logging. | Én design å bygge og teste. Føles mest som en «ekte» mobilapp. | Mye tom plass på PC, som er der sensor tester appen. |
| **A3 · To store fliser** | Forsiden har bare dagens lapp og to store fliser, Mat og Trening, som hver åpner sin seksjon. | Passer best med briefen (få knapper, hver seksjon leder steg for steg). | Brukeren må trykke seg inn for å se detaljer. |

Se dem samlet i `galleri.html`.
