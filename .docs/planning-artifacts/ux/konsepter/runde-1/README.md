# UX-konsepter, runde 1

Laget 2026-11-10 av Osman Khalid med Claude Code og Impeccable-skillen. SVG-ene er generert med et Python-skript, som vist i forelesningen 9. november. Alle data i skissene er fiktive (Sara fra PRD UJ-1 til UJ-4).

Hvert konsept viser **Dagsoversikten** (forsiden, FR-26) på PC og mobil, med samme innhold, slik at de kan sammenlignes direkte.

| Konsept | Idé | Styrke | Risiko |
|---|---|---|---|
| **A · Kjøleskapstavla** | Uka som en planleggingstavle på kjøleskapet. Magneter viser hvilke dager som har mat og trening logget. | Rolig og ryddig. Ukestripa gjør det lett å bytte dato (FR-27). Én tydelig hovedknapp. | Kan bli litt nøktern og «kontoraktig» hvis farger og magneter ikke får nok plass. |
| **B · Treningsdagboka** | Den rutete skriveboka med rød marg. Datoene står i margen, og mat og økt føres som en loggbok med håndskrift. | Gjenkjennelig for alle som har ført treningsdagbok. Kcal-budsjettet vises som en linje, ikke bare et tall. | Håndskriftfont kan være vanskeligere å lese (NFR-10). Rutenettet kan føles travelt. |
| **C · Kartlobene** | Inspirert av et parkkart. Mat og Trening er to store, flate fargeområder, og knappene er gule kapsler. | Vennlig og motiverende. Skillet mellom Mat og Trening er tydelig med en gang. | Mest lekent og minst «seriøst». Organiske former er vanskeligere å bygge og å få responsive. |

Se dem samlet i `galleri.html`.

## Neste steg

1. Gruppa ser på konseptene og velger **ett hovedkonsept**.
2. Vi noterer hva som skal hentes fra de andre konseptene i `../decisions.md`.
3. Runde 2 lages ut fra beslutningene, gjerne med 3 varianter igjen.
