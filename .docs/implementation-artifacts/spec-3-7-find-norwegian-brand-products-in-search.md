## Intent

**Problem:** Search only finds Matvaretabellen staples, so brand products such as "Tine Lettmelk" need a barcode.

**Approach:** Add `python -m app.cli import-off-norway`, which fetches the 2 000 most scanned Norwegian products from the Open Food Facts search API (decision by Osman, 2026-11-16, option A), keeps those with a name and kcal per 100 g, and writes them to a committed seed file. `seed_if_empty` loads that file as shared `off` items, skipping barcodes already cached, so the examiner never needs network access. Search then finds them like any other shared item.

## Boundaries & Constraints

**Always:** Fetch `https://world.openfoodfacts.org/api/v2/search?countries_tags_en=norway&sort_by=unique_scans_n&page_size=100&page=N&fields=code,product_name,product_name_nb,brands,nutriments,serving_quantity`, pages 1–20, with the app's User-Agent from `ports/off.py`, at most 10 search requests per minute (sleep ≥ 6 s between pages), 30 s timeout, stdlib only. Reuse `parse_product()` and `is_valid_ean()` from story 3.3 for name, kcal (0–900), macros and serving size; skip invalid barcodes and duplicates. Output `backend/app/seed/data/off_norway.json` (sorted by barcode, fields: `barcode`, `name`, `kcal_per_100g`, `protein_g`, `carbs_g`, `fat_g`, `serving_size_g`) and `backend/app/seed/data/OFF_LICENSE.md` (ODbL 1.0 notice, source, date, "Data fra Open Food Facts", that the file is a derived database under ODbL). The command prints "Fetched N products, kept M." and never runs in tests (tests use a stubbed fetch). `seed_if_empty` (local only) loads the file after Matvaretabellen, inserting only barcodes not already present as shared items, and logs how many were added; running it twice adds nothing. Imported items: `source="off"`, `owner_id` NULL, `external_id`=barcode. Search already shows "Data fra Open Food Facts" for OFF results (3.3). README gets a short "Oppdatere matdata" note with the command. The import is run once in this story and its output committed.

**Never:** No import of all ~29 600 Norwegian products. No network call at app start or in tests. No editing of OFF values.

## Implementation Notes

- The import lives in `backend/app/ports/off_import.py` (`fetch_products`, `select_products`, `write_outputs`, `run_import`); all pages are fetched before anything is written, and both files are written via a temp file + `os.replace`, so a failed page leaves the committed files untouched. A product needs `product_name_nb` or `product_name` (brand alone is not a name); name, kcal and macros come from `parse_product()`. The first (most scanned) occurrence of a barcode wins.
- `seed_off_items()` runs after the Matvaretabellen seed on every local start and skips barcodes already present as shared items, so a second start adds nothing; a missing `off_norway.json` adds nothing.
- 2026-11-16: the one approved live run stopped at page 1 with HTTP 503 from the OFF search API (no file written). `off_norway.json` and `OFF_LICENSE.md` are therefore not yet generated; a new run needs the human's go-ahead.
