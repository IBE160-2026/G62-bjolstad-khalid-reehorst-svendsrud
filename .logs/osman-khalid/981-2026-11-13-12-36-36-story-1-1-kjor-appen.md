# Story 1.1: Kjør appen med én kommando

## 2026-11-13 kl. 12:36 — Osman Khalid

### Oppgave
Implementere story 1.1 etter spesifikasjonen: grunnmuren for monorepoet (FastAPI-backend, Next.js-frontend, PostgreSQL) som starter med én `docker compose up`, med helse-endepunkt via `/api`-rewrite, felles feilformat, Alembic, sikkerhetssperre for produksjonsinnstillinger, genererte API-typer og «Kom i gang» i README.

### Plan
- Spesifikasjon: [spec-1-1-run-app-one-command.md](../../.docs/implementation-artifacts/spec-1-1-run-app-one-command.md), med [epic-1-context.md](../../.docs/implementation-artifacts/epic-1-context.md) og [ARCHITECTURE-SPINE.md](../../.docs/planning-artifacts/architecture/architecture-prompt-force-2026-11-13/ARCHITECTURE-SPINE.md).
- Frontend med `create-next-app@16.4.6`, backend med uv og `alembic init`, versjoner låst etter arkitekturen.
- Verifisere med kommandoene i spesifikasjonens Verification-seksjon.

### Resultat
- Nye filer: `docker-compose.yml`, `.env.example`, `db/init/01-create-test-db.sql`, `backend/` (app/core settings/db/errors, health-modul, seed-stub, cli, Alembic med tom baseline 0001, `scripts/export_openapi.py`, `openapi.json`, tester, Dockerfile + entrypoint), `frontend/` (Next.js 16.4.6, rewrite i `next.config.ts`, generert `src/lib/api/schema.d.ts` + `client.ts`, side som viser «Backend: ok», TanStack Query-provider, Vitest, Dockerfile).
- README: nye seksjoner «Kom i gang», «Tester», «Utvikling»; Status og Mappestruktur oppdatert.
- Spesifikasjonen: alle oppgaver krysset av, avvik ført i Implementation Notes (bl.a. at API-klienten bruker `baseUrl: ""` fordi stiene alt starter med `/api`).
- Verifisert: alle tre tjenestene «healthy»; `curl localhost:3000/api/health` → `{"status":"ok"}`; `/api/nope` → 404 med `not_found`-konvolutt; headless Chrome viser «Backend: ok»; `docker compose exec backend pytest -q` → 17 bestått; `npm run test -- --run` (2 bestått), `npm run lint` og `tsc` rene; `APP_ENV=production SESSION_SECRET= docker compose run --rm backend true` → exit 1 med tydelig melding (også for standardhemmeligheten); port 8000 ikke publisert; `git status` viser ingen `.env`, `.next`, `node_modules` eller `.venv`.
- Koden er ikke committet (story-branch `story/1-1-run-app-one-command`).

### Åpne punkter
- Starlette advarer om at `httpx` i TestClient er utfaset til fordel for `httpx2`; arkitekturen låser httpx 0.28.1, så versjonen bør vurderes i arkitekturen.
- Containerne har ingen bind mounts, så kodeendringer krever `docker compose up --build`; vurder hot reload for utvikling.
